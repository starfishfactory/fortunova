## 1. 전략 요약

### 1.1 한 문장 정의

> **Fortunova는 LLM 기반 사주 분석 엔진을 통해 30~40대 직장인에게 매일 개인화된 운세와 실질적 실행 가이드를 제공하는 AI 네이티브 사주 구독 서비스다.**

### 1.2 핵심 전략 파라미터

| 항목 | 결정 | 근거 |
|------|------|------|
| 포지셔닝 | AI 네이티브 사주 | 기존 앱은 GPT를 "얹은" 수준. Fortunova는 LLM이 제품의 핵심 |
| 타깃 | 30~40대 직장인 | 사주 콘텐츠 주 소비층(27세+), 높은 결제 의향, 실질적 고민 보유 |
| 핵심 경험 | 데일리 운세 + 실행 가이드 | 구독 유지의 핵심 = 매일 새로운 가치 |
| 수익모델 | 구독 (월/연) | 데일리 콘텐츠와 궁합 최적, 예측 가능한 매출 |
| 프레임워크 | Flutter (Dart) | 솔로/소규모 팀의 크로스 플랫폼 최적 선택 |
| MVP 기간 | 12개월 (완성도 우선) | 30~40대 타깃은 UI 품질에 민감, 반쯤 만든 앱은 이탈 |

### 1.3 Fortunova가 기존 앱과 다른 점

```
기존 앱: 사주 데이터 입력 → 사전 정의된 텍스트 출력 → 끝
Fortunova: 사주 명식 분석 → LLM 개인 맥락 결합 → 오늘의 실행 가이드 생성 → 결과 추적 → 패턴 학습 → 점점 더 정교한 가이드
```

핵심 차별화는 **"해석에서 실행까지"** 그리고 **"실행 결과가 다시 해석을 정교하게 만드는 피드백 루프"**에 있다.

## 2. 시장 기회 분석

### 2.1 기존 시장의 빈틈 (분석 데이터 기반)

이전 경쟁 분석에서 도출한 4가지 앱 유형과 Fortunova의 위치:

```
                    정보 깊이 (깊음)
                         ↑
                         |
              정통사주 ●  |  ● Fortunova (목표 위치)
                         |
         ─────────────────────────────── → 실행 연결성 (높음)
                         |
              점신 ●     |     ● (시장 공백)
                         |
          포스텔러 ●     |  ● 헬로우봇
                         |
                    정보 깊이 (얕음)
```

Fortunova가 노리는 포지션: **깊이 있는 사주 분석 + 높은 실행 연결성** — 현재 이 사분면에 강력한 플레이어가 없다.

### 2.2 타깃 사용자 페르소나

**페르소나 1: "커리어 고민러" 김대리 (33세, 여성)**
- IT 회사 5년차, 이직 고민 중
- 매일 아침 점신으로 운세 확인하지만 "그래서 뭘 어쩌라고?"라는 생각
- 원하는 것: "오늘 면접 보러 가도 되는 날인지, 어떤 태도로 임해야 하는지"
- 결제 의향: 월 9,900~14,900원 가능 (커피 2~3잔 가격)

**페르소나 2: "재물 관리자" 박과장 (38세, 남성)**
- 중견기업 과장, 주식·부동산 투자에 관심
- 포스텔러로 재물운 보지만 "구체적 타이밍"이 없어 아쉬움
- 원하는 것: "이번 달 투자하기 좋은 시기, 피해야 할 날"
- 결제 의향: 연간 구독 선호 (할인 혜택에 민감)

**페르소나 3: "인간관계 고민러" 최팀장 (42세, 여성)**
- 팀장 승진 후 팀원 관리 스트레스
- 헬로우봇 써봤지만 "너무 가볍다"고 느낌
- 원하는 것: "이 팀원과 어떻게 소통해야 하는지, 오늘 회의에서의 전략"
- 결제 의향: 가치가 증명되면 프리미엄도 가능

### 2.3 TAM-SAM-SOM

| 시장 | 규모 | 근거 |
|------|------|------|
| TAM | 1.4조원+ | 한국 점술 시장 전체 (현금 거래 미추적분 포함 시 더 큼) |
| SAM | 2,000억원 | 디지털 운세/사주 앱 시장 (앱 매출 + 상담 매출) |
| SOM (3년) | 50~100억원 | 유료 구독 10~20만명 × 월 5,000~9,900원 |

## 3. MVP 정의

### 3.1 MVP 핵심 가설

> **"30~40대 직장인은 사주 기반의 개인화된 데일리 실행 가이드에 월 9,900원을 지불할 의향이 있다"**

이 가설을 검증하기 위해 MVP에서 반드시 구현해야 하는 것과 하지 않아도 되는 것을 구분한다.

### 3.2 MVP Must-Have vs Nice-to-Have vs Not-Now

**Must-Have (MVP 필수)**

| 기능 | 설명 | 가설 검증 기여도 |
|------|------|-----------------|
| 사주 프로필 등록 | 생년월일+시+성별 입력, 사주 명식 자동 생성 | 기본 인프라 |
| 데일리 운세 생성 | LLM이 사주 명식 + 오늘 일진 기반 개인화 운세 생성 | 핵심 가치 |
| 실행 가이드 | 운세를 "오늘 해야 할 것 / 피해야 할 것"으로 변환 | 핵심 차별화 |
| 운세 카테고리 | 총운, 커리어운, 재물운, 인간관계운 (4개) | 타깃 니즈 매칭 |
| 구독 결제 | 무료 체험 7일 → 월 9,900원 / 연 79,900원 | 수익모델 검증 |
| 푸시 알림 | 매일 아침 7시 데일리 운세 알림 | 리텐션 루프 |
| AI 질문 (월 10회) | 사주 기반 AI에게 자유 질문 (커리어, 관계 등) | AI 가치 검증 |

**Nice-to-Have (출시 후 빠르게 추가)**

| 기능 | 설명 | 우선순위 |
|------|------|---------|
| 주간/월간 리포트 | 이번 주/달의 흐름 요약 | 높음 |
| 실행 체크리스트 | 가이드를 체크리스트로 변환, 실행 추적 | 높음 |
| 궁합 분석 | 2인 사주 비교 분석 | 중간 |
| 위젯 | iOS/Android 홈스크린 위젯 | 중간 |

**Not-Now (Phase 3 이후)**

| 기능 | 설명 | 보류 사유 |
|------|------|----------|
| 타로 | 별도 콘텐츠 체계 필요 | 포커스 분산 |
| 전문가 상담 연결 | O2O 인프라 구축 필요 | 리소스 과다 |
| 만세력 Pro | 전문가 도구 | 타깃 불일치 |
| 커뮤니티 | 소셜 기능 | MVP 범위 초과 |
| 점성술/손금/풍수 | 멀티 장르 확장 | 포커스 분산 |

### 3.3 MVP 사용자 여정 (User Journey)

```
[Day 0] 앱 설치 & 온보딩
  ├─ 간결한 3단계 온보딩: "Fortunova가 뭔지" → "생년월일 입력" → "첫 사주 분석"
  ├─ 첫 사주 명식 카드 생성 (시각적으로 아름다운 나만의 사주 카드)
  └─ 무료 체험 7일 시작 안내

[Day 1~7] 무료 체험 기간
  ├─ 매일 아침 7시 푸시: "오늘의 Fortunova 가이드가 도착했어요"
  ├─ 앱 진입 → 오늘의 운세 점수 (100점 만점) + 한 줄 핵심 메시지
  ├─ 스크롤 → 커리어운 / 재물운 / 인간관계운 상세 + 실행 가이드
  ├─ AI 질문 3회 무료 체험 (예: "오늘 팀장에게 연봉 협상해도 될까요?")
  └─ Day 6: 구독 전환 유도 ("체험이 내일 종료됩니다")

[Day 8+] 구독 사용자
  ├─ 데일리 운세 + 실행 가이드 (매일 갱신)
  ├─ AI 질문 월 10회
  ├─ 과거 운세 아카이브 열람
  └─ 주간/월간 리포트 (Phase 2에서 추가)
```

### 3.4 MVP 화면 구성 (Information Architecture)

```
[홈 탭]
  ├─ 오늘의 운세 점수 (원형 스코어)
  ├─ 핵심 메시지 (1줄)
  ├─ 커리어운 카드 + 실행 가이드
  ├─ 재물운 카드 + 실행 가이드
  ├─ 인간관계운 카드 + 실행 가이드
  └─ 오늘의 행운 키워드 / 피해야 할 키워드

[AI 상담 탭]
  ├─ 채팅 인터페이스 (심플, 성숙한 톤)
  ├─ 질문 예시 추천
  └─ 남은 질문 횟수 표시

[나의 사주 탭]
  ├─ 사주 명식 카드 (비주얼)
  ├─ 오행 분석 요약
  ├─ 올해 대운/세운 흐름
  └─ 프로필 관리 (가족/지인 추가)

[설정 탭]
  ├─ 구독 관리
  ├─ 알림 설정
  ├─ 과거 운세 아카이브
  └─ 고객 지원
```

## 5. Phase 1: Foundation (M1~M3)

> **목표**: 제품의 기술적·학술적 기반을 다진다

### 5.1 핵심 과업

**사주 명리학 도메인 학습 (M1~M2)**

LLM에 명리학 지식을 주입하기 전에 팀(솔로) 자체가 도메인을 이해해야 한다.

| 학습 영역 | 상세 내용 | 산출물 |
|----------|----------|--------|
| 사주 기초 | 천간(10), 지지(12), 60갑자, 오행 상생상극 | 도메인 지식 문서 |
| 명식 구성 | 연주·월주·일주·시주의 의미와 상호작용 | 만세력 계산 로직 명세 |
| 대운·세운 | 10년 대운, 연운, 월운, 일운의 흐름 | 시간축 운세 생성 로직 |
| 신살 체계 | 주요 신살(역마, 도화, 문창 등)의 의미 | 신살 해석 프롬프트 |
| 일진 분석 | 일간(日干)과 당일 간지의 관계 | 데일리 운세 생성 핵심 로직 |

**기술 스택 결정 및 환경 구축 (M1)**

| 레이어 | 기술 선택 | 선정 이유 |
|--------|----------|----------|
| 프론트엔드 | Flutter 3.x (Dart) | 크로스 플랫폼, 성능, 솔로 팀 효율 |
| 상태관리 | Riverpod | Flutter 최신 표준, 코드 구조화 |
| 백엔드 | Supabase 또는 Firebase | BaaS로 서버 운영 부담 최소화 |
| AI 엔진 | Claude API / GPT-4 API | 명리학 추론에 최적 (구조화된 프롬프트) |
| 만세력 엔진 | 자체 Dart 라이브러리 | 핵심 로직, 외부 의존도 최소화 |
| 결제 | RevenueCat | iOS/Android 구독 통합 관리 |
| 분석 | Mixpanel 또는 Amplitude | 사용자 행동 추적, 구독 전환 분석 |
| CI/CD | Codemagic 또는 GitHub Actions | Flutter 빌드 자동화 |

**만세력 계산 엔진 프로토타입 (M2~M3)**

사주 앱의 핵심 인프라. 외부 API 의존 없이 자체 만세력 엔진을 구축한다.

```
입력: 양력 생년월일 + 생시 + 성별
  ↓
처리: 양력→음력 변환 → 절기 보정 → 사주 명식 도출
  ↓
출력: 연주(年柱), 월주(月柱), 일주(日柱), 시주(時柱)
     + 오행 분포 + 십성 + 12운성 + 주요 신살
```

구현 범위:
- 양력↔음력 변환 (1900~2100년)
- 절기 기반 월주 결정
- 동경시/서머타임 보정 옵션
- 대운수 계산 (남녀 순역행 구분)
- 세운(연운) 간지 계산
- 일진(일간) 계산 (데일리 운세의 핵심)

### 5.2 Phase 1 마일스톤

## 6. Phase 2: Core AI Engine (M3~M5)

> **목표**: Fortunova의 핵심 차별화인 AI 사주 해석 엔진을 구축한다

### 6.1 AI 엔진 아키텍처

```
[사용자 입력]
     ↓
[만세력 엔진] → 사주 명식 (구조화된 데이터)
     ↓
[컨텍스트 빌더]
  ├─ 사주 명식 데이터
  ├─ 오늘 일진 (당일 천간지지)
  ├─ 현재 대운/세운/월운 위치
  ├─ 사용자 프로필 (직업군, 관심 영역)
  └─ 이전 피드백 히스토리 (Phase 7에서 활성화)
     ↓
[LLM 프롬프트 엔진]
  ├─ System Prompt: 명리학 전문가 페르소나 + 해석 규칙
  ├─ Context: 위 데이터 전체
  └─ Task: "오늘의 실행 가이드 생성"
     ↓
[후처리 레이어]
  ├─ 운세 점수 산출 (0~100)
  ├─ 카테고리별 분류 (커리어/재물/인간관계/건강)
  ├─ 실행 가이드 추출 (DO / DON'T)
  └─ 행운 키워드 생성
     ↓
[최종 출력] → 프론트엔드 렌더링
```

### 6.2 프롬프트 엔지니어링 전략

**프롬프트 설계 원칙:**

1. **구조화된 입력**: 명식을 자연어가 아닌 구조화된 JSON으로 전달
2. **규칙 기반 해석 + LLM 표현력**: 오행 상생상극 등 규칙은 명시, 해석과 표현은 LLM에 위임
3. **톤 앤 매너**: 신비로움과 실용성의 균형. "점쟁이 말투"가 아닌 "지적인 인생 코치" 톤
4. **실행 가능성**: 모든 운세에는 반드시 구체적 실행 가이드 포함

**프롬프트 구조 (예시 골격):**

```
[System]
당신은 30년 경력의 명리학 전문가이자 현대적 라이프 코치입니다.
사주 명식 데이터를 분석하여 오늘의 운세와 실행 가이드를 제공합니다.

해석 규칙:
- 일간(日干)과 오늘 일진의 관계를 최우선으로 분석
- 현재 대운/세운의 맥락에서 오늘의 위치를 해석
- 반드시 "오늘 해야 할 것"과 "오늘 피해야 할 것"을 포함
- 30~40대 직장인의 맥락에서 실용적 조언 제공
- 미신적 표현을 배제하고, 통찰력 있는 코칭 톤 유지

출력 형식: [구조화된 JSON]

[User]
{사주 명식 JSON + 오늘 일진 + 대운/세운 정보 + 사용자 프로필}
```

### 6.3 데일리 운세 생성 파이프라인

```
[매일 새벽 4시] 배치 프로세스
  ├─ 오늘 일진(日辰) 계산
  ├─ 전체 활성 구독자 리스트 조회
  ├─ 각 사용자별:
  │   ├─ 사주 명식 + 오늘 일진 → 컨텍스트 빌드
  │   ├─ LLM API 호출 → 운세 생성
  │   ├─ 후처리 (점수 산출, 카테고리 분류)
  │   └─ 캐시 저장
  └─ [아침 7시] 푸시 알림 발송

[사용자 앱 진입 시]
  ├─ 캐시된 운세 즉시 표시 (로딩 없음)
  └─ AI 질문은 실시간 API 호출
```

**비용 최적화 전략:**
- MVP 단계에서는 사용자 수가 적으므로 실시간 생성도 가능
- 1,000명 이상 시 배치 생성으로 전환
- 프롬프트 최적화로 토큰 사용량 최소화 (목표: 응답당 500~800 토큰)
- Claude Haiku 또는 GPT-4o-mini 등 경량 모델로 데일리 운세 생성, 심층 질문만 상위 모델

## 7. Phase 3: MVP Build (M5~M8)

> **목표**: 완성도 높은 앱을 구현한다 (30~40대가 "이건 제대로 만들었네"라고 느끼는 수준)

### 7.1 디자인 시스템

**비주얼 아이덴티티:**

Fortunova는 기존 사주 앱의 "신비로운 다크" 또는 "귀여운 캐릭터" 접근을 벗어나, **"프리미엄 인사이트 툴"** 느낌을 추구한다.

| 요소 | 방향 | 레퍼런스 |
|------|------|---------|
| 컬러 | 딥 네이비 + 골드 액센트 + 화이트 | Bloomberg, Calm 앱 |
| 타이포 | 세리프 제목 + 산세리프 본문 | 고급스러움 + 가독성 |
| 아이콘 | 라인 아이콘 (미니멀) | SF Symbols 스타일 |
| 일러스트 | 추상적 천체/기하학 패턴 | 명리학적이되 현대적 |
| 모션 | 부드러운 전환, 과하지 않은 애니메이션 | 신뢰감 있는 움직임 |

**디자인 원칙:**
1. **Calm Authority**: 차분하지만 권위 있는 (점쟁이가 아닌 컨설턴트)
2. **Glanceable**: 한눈에 핵심 파악 (바쁜 직장인)
3. **Premium Feel**: 구독료가 아깝지 않은 시각적 품질
4. **Data-Beautiful**: 사주 데이터를 아름답게 시각화

## 14. Phase 10: Scale & Moat (M31~M36)

> **목표**: 압도적 데이터 해자와 글로벌 확장 기반 마련

### 14.1 데이터 해자 (Data Moat)

3년간 축적된 데이터가 Fortunova의 핵심 경쟁력이 된다:

```
사용자 수 × 일 수 × 운세 생성 = 데이터 볼륨

100,000명 × 365일 × 4카테고리 = 약 1.46억 건의 운세-피드백 쌍

→ 이 데이터로 자체 사주 AI 모델 Fine-tuning
→ 범용 LLM 대비 사주 해석 정확도 압도적 우위
→ 후발 주자가 따라오기 어려운 데이터 해자 완성
```

### 14.2 자체 AI 모델

| 단계 | 내용 | 시기 |
|------|------|------|
| 1단계 | 프롬프트 엔지니어링 (외부 LLM 활용) | Phase 2~7 |
| 2단계 | Fine-tuning (자체 데이터로 외부 모델 튜닝) | Phase 8~9 |
| 3단계 | 자체 소형 모델 (Fortunova-LLM) | Phase 10 |

3단계에서는 사주 해석에 특화된 경량 모델을 자체 운영함으로써:
- API 비용 대폭 절감
- 응답 속도 향상
- 독자적 기술 자산 확보

### 14.3 글로벌 확장 준비

**1차 확장 시장: 동아시아**
- 일본: 사주(四柱推命) 시장 존재, 운세 앱 수요 높음
- 대만/홍콩: 중화권 명리학 문화
- 베트남: 음력 문화 + 모바일 퍼스트 시장

**2차 확장 시장: 서양**
- 점성술(Astrology) 프레임으로 리브랜딩
- Co-Star, The Pattern 등 점성술 앱 시장 진입
- "Eastern Wisdom + AI" 포지셔닝
