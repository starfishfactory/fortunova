## 1. AI 엔진 아키텍처

```
[사용자 프로필] → [만세력 엔진 (Python)] → 사주 명식 JSON
     ↓
[컨텍스트 빌더]
  ├─ 사주 명식 + 오행 + 신살
  ├─ 오늘 일진 (당일 천간지지)
  ├─ 대운/세운/월운 위치
  ├─ 불변 해석 캐시 (장기 해석 재활용)
  └─ 사용자 프로필 메타 (Phase 7 확장)
     ↓
[FastAPI → Claude API 호출]
  ├─ System Prompt: 페르소나 + 규칙 + 금기
  ├─ Context: 위 데이터
  └─ Task: 실행 가이드 생성
     ↓
[후처리 (Python)]
  ├─ 운세 점수 산출 (0~100)
  ├─ DO/DON'T 추출·구조화
  ├─ 일관성 검증 (모순 검출)
  └─ 키워드 추출
     ↓
[PostgreSQL 캐시 저장]
```

모든 로직이 Python 한 코드베이스에서 동작한다. 프롬프트 엔진, 만세력, 후처리, API 서버가 하나의 FastAPI 프로젝트 안에 통합.

## 2. 일관성 보장 시스템

| 레이어 | 내용 | 캐시 주기 |
|--------|------|----------|
| 불변 해석 | 명식 기본 해석, 올해 세운 | 연 1회 갱신 |
| 가변 해석 | 일진 기반 오늘의 DO/DON'T | 매일 생성 |
| 모순 검출 | 오늘 생성 vs 장기 해석 자동 비교 | 매일 검사 |

## 3. 데일리 운세 파이프라인

```
[매일 새벽 4시] FastAPI 서버 내 APScheduler 또는 cron
  ├─ 오늘 일진 계산
  ├─ 활성 사용자별:
  │   ├─ 불변 캐시 로드
  │   ├─ 컨텍스트 빌드 → Claude API 호출
  │   ├─ 후처리 + 일관성 검증
  │   └─ PostgreSQL에 캐시 저장
  └─ [아침 7시] FCM 푸시 발송

[앱 진입 시] Flutter → FastAPI GET /fortune/today
  └─ PostgreSQL에서 캐시된 운세 즉시 반환 (LLM 호출 없음)
```

Ultra MVP (50~100명) 단계에서는 배치 대신 앱 열 때 실시간 생성도 가능. 비용 월 ~3만원.

## 4. 실행 가이드 품질 기준

| 기준 | 좋은 예 | 나쁜 예 |
|------|--------|--------|
| 구체성 | "오전 미팅에서 적극 발언" | "좋은 하루가 될 것" |
| 실행 가능 | "점심 후 10분 산책 추천" | "우주 에너지를 느끼세요" |
| 직장인 맥락 | "상사에게 제안서 보내기 좋은 날" | "좋은 일이 생길 수 있다" |
| 비미신적 | "에너지 흐름상 오전이 유리" | "액운이 낀다" |

## 5. 프롬프트 테스트 자동화

```python
# tests/test_fortune_quality.py
# 30개 사주 × 7개 일진 = 210건 배치 생성
# 자동 검사: JSON 형식, DO/DON'T 포함, 점수 범위, 금기 키워드 부재
# 수동 검사: 명리학 타당성, 실행 가능성 (샘플링)
```

Python이므로 pytest로 프롬프트 품질 테스트를 자동화할 수 있다.

## 6. Gate 1 판정

| 항목 | 기준 |
|------|------|
| 만세력 정확도 | 200건 교차 검증 100% |
| 프롬프트 일관성 | 같은 입력 10회 → 핵심 해석 80%+ 일관 |
