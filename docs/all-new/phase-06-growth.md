## 성장 레버

**1. 궁합 (바이럴 핵심)**: "이 동료와 업무 궁합" → 상대방 앱 설치 유도 → 자연 유입

**2. 주간/월간 리포트**: Basic 이상 구독자에게 주간 흐름 요약

**3. 실행 체크리스트 + 리뷰**: DO/DON'T → 체크리스트 → 저녁 리뷰 → 피드백 루프 시작

**4. Premium 플랜**: 12,900원/월, AI 무제한 + 리포트 + 궁합 5회/월
