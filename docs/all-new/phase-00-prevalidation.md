# Phase 0: Pre-validation (M1~M2)

> **상위 문서**: [메인 로드맵](../README.md)
> **목표**: 앱을 만들기 전에 "실행 가이드형 데일리 운세"에 실제 수요가 있는지 검증
> **Gate 0**: 랜딩페이지 전환 5%+ AND 수동 MVP 리텐션 50%+

---

## 검증 방법 (4가지)

### 1. 랜딩페이지 테스트 (M1 W1~2)
- Framer/Carrd로 1페이지 제작 (1~2일)
- 카피: "매일 아침, 사주가 알려주는 오늘의 전략 — 곧 출시"
- CTA: 이메일 수집 ("출시 알림 받기")
- Instagram/Facebook 타깃 광고 30~40대 (10~20만원)
- **성공 기준**: 전환율 5%+, 이메일 100명+

### 2. 가격 민감도 조사 (M1 W2~3)
- Van Westendorp 4개 질문 (구글폼, 이메일 등록자 대상)
- 최적 가격 범위 도출

### 3. 수동 MVP (M1 W3 ~ M2 W2, 2주)
- 10~15명에게 카카오톡으로 매일 아침 수동 운세+실행가이드 발송
- 온라인 만세력으로 명식 확인 후 직접 작성
- **측정**: 읽음 확인률, 14일 중 7일 이상 열람 시 성공

### 4. Fake Door 테스트 (M1~M2 병행)
- Instagram 광고 2세트: "사주 프레이밍" vs "자기이해 프레이밍"
- 클릭률·전환율 비교 → 마케팅 방향 결정

---

## Gate 0 판정

| 시나리오 | 기준 | 결정 |
|---------|------|------|
| 🟢 Green | 전환 5%+ AND 리텐션 50%+ AND 결제의향 30%+ | Phase 1 진행 |
| 🟡 Yellow | 2개 충족, 1개 미달 | 원인 분석 후 2주 재검증 |
| 🔴 Red | 2개 이상 미달 | 컨셉 피벗 |

## 예산: ~30만원 (광고+도메인)
